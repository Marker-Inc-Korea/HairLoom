# B-SCREENS — 살롱 상담용 화면 설계

> 화면 수는 6개로 유지하되 명칭과 우선순위를 살롱 상담 흐름으로 바꾼다. 준오헤어식 큰 이미지/짧은 라벨/넓은 여백을 기준으로 한다.

## 공통 화면 원칙

- 손님용 영역의 글은 최소화한다: 제목, 카테고리, 스타일명, 선택 상태만 노출.
- 디자이너용 근거/설명은 접힘 패널이나 하단 작은 메모로 숨긴다.
- 긴 카드 설명 대신 큰 이미지, 색칩, A/B/C 비교를 사용한다.
- 모바일보다 매장 태블릿/데스크톱 상담 장면을 우선한다.

## 현재 원본 헤어 모듈 한계 근거

- 원본 헤어 모듈은 `전체 모듈` 복귀 버튼과 `01 스타일 결정 / 02 사진에 적용 / 03 저장 기록` 탭 안에 있어 헤어 살롱 단독 서비스처럼 보이지 않는다.
- 스타일 목록은 충분하지만 “손님에게 보여주는 카탈로그”라기보다 앱 설정 카드에 가깝다.
- 염색은 계통별 카드와 칩이 있으나 살롱 컬러 차트처럼 큼직하게 비교되지 않는다.

## 1. Gate — 브랜드 진입 / 홈

### 텍스트 와이어

```text
┌──────────────────────────────────────────────┐
│                HAIR DESIGN                   │
│                                              │
│   [대형 이미지: 여성 스타일]  [대형 이미지: 남성 스타일] │
│                                              │
│          CUT     COLOR     PREVIEW           │
└──────────────────────────────────────────────┘
```

### 디자인 의도

설명형 홈이 아니라 살롱 브랜드의 게이트처럼 보인다. 손님은 문장을 읽기 전에 “헤어 스타일을 고르는 화면”이라는 인상을 받아야 한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | 대표 여성/남성 헤어 샘플 2장과 `CUT / COLOR / PREVIEW`만 표시. |
| 로딩 | 대형 이미지 영역 skeleton. |
| 오류 | 이미지 fallback 블록 + `CUT / COLOR` 진입은 유지. |
| 완료 | 최근 상담/저장 결과가 있으면 하단에 작은 `RECENT` 카드 1개 표시. |

## 2. Style Board — 스타일 보드 / 탐색

### 텍스트 와이어

```text
┌──────────────────────────────────────────────┐
│ CUT                                          │
│ [ Women ] [ Men ] [ Short ] [ Medium ] [ Long ]│
│                                              │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
│ │ 사진    │ │ 사진    │ │ 사진    │ │ 사진    │ │
│ │ Airy   │ │ Hush   │ │ Bob    │ │ Comma  │ │
│ │레이어드 │ │허쉬컷   │ │단발    │ │쉼표머리 │ │
│ └────────┘ └────────┘ └────────┘ └────────┘ │
└──────────────────────────────────────────────┘
```

### 디자인 의도

살롱 벽면의 스타일 카탈로그처럼 보이게 한다. 카드 안 문장은 없애고, 이미지와 짧은 이름만으로 선택하게 한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | 여성/남성 대표 8개 스타일을 큐레이션해 보여준다. |
| 로딩 | 동일 비율 이미지 skeleton grid. |
| 오류 | 실패한 카드만 neutral placeholder로 대체. |
| 완료 | 선택 카드는 berry ring, rose fill, `SELECTED` 라벨로 표시. |

## 3. Color Board — 컬러 차트 / 탐색

### 텍스트 와이어

```text
┌──────────────────────────────────────────────┐
│ COLOR                                        │
│ [ Black ] [ Brown ] [ Beige ] [ Ash ] [ Vivid ]│
│                                              │
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐          │
│ │색칩   │ │색칩   │ │색칩   │ │색칩   │          │
│ │Ash B │ │Cacao │ │Rose B│ │Copper│          │
│ └──────┘ └──────┘ └──────┘ └──────┘          │
└──────────────────────────────────────────────┘
```

### 디자인 의도

색상환은 상담 현장에서 과할 수 있으므로 메인은 살롱 컬러 차트로 둔다. 웜/쿨/명도/채도는 칩 아래의 작은 태그로만 제공한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | Black/Brown/Ash 대표 컬러를 먼저 보여준다. |
| 로딩 | 색칩 skeleton과 계열 탭 skeleton. |
| 오류 | 컬러 분석 태그만 숨기고 색칩 선택은 유지. |
| 완료 | 선택 색은 큰 칩, 선택 ring, Preview 화면의 After 배경 톤에 반영. |

## 4. Client Preview — 고객 시안 / 적용

### 텍스트 와이어

```text
┌──────────────────────┬──────────────────────┐
│ BEFORE               │ AFTER                │
│ 원본 또는 샘플 사진    │ 선택 스타일 적용 시안  │
└──────────────────────┴──────────────────────┘
│ Airy Layer · Ash Brown · Soft Wave           │
│ [다른 스타일] [비교에 추가] [저장]             │
```

### 디자인 의도

상담의 중심 화면이다. 점수와 분석보다 Before/After가 먼저 보이고, 하단에 선택한 레시피만 짧게 표시한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | 샘플 얼굴/헤어 실루엣으로 미리보기 가능, 사진 업로드 강제 없음. |
| 로딩 | After 영역에 진행 상태만 크게 표시. |
| 오류 | After 영역에 실패 메시지와 재시도 버튼, 선택 레시피 유지. |
| 완료 | Before/After 2분할, 하단에 선택 레시피와 저장/비교 CTA. |

## 5. Compare Board — A/B/C 비교 / 비교

### 텍스트 와이어

```text
┌──────────────┬──────────────┬──────────────┐
│ A            │ B            │ C            │
│ 이미지        │ 이미지        │ 이미지        │
│ Soft Bob     │ Airy Layer   │ Comma        │
└──────────────┴──────────────┴──────────────┘
```

### 디자인 의도

살롱 상담에서는 “1등/2등”보다 “A안/B안/C안”이 자연스럽다. 후보를 같은 크기로 보여주고 손님이 고르게 한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | `비교할 시안을 추가하세요`와 Style Board CTA. |
| 로딩 | 3분할 카드 skeleton. |
| 오류 | 깨진 후보만 제거하고 남은 후보는 유지. |
| 완료 | A/B/C 카드, 선택 라벨, 저장/룩북 이동 CTA. |

## 6. Lookbook — 저장 룩북 / 기록

### 텍스트 와이어

```text
┌──────────────────────────────────────────────┐
│ LOOKBOOK                                     │
│ [ Today ] [ Cut ] [ Color ] [ Client ]        │
│                                              │
│ ┌──────┐ ┌──────┐ ┌──────┐                  │
│ │시안   │ │시안   │ │시안   │                  │
│ │날짜   │ │날짜   │ │날짜   │                  │
│ └──────┘ └──────┘ └──────┘                  │
└──────────────────────────────────────────────┘
```

### 디자인 의도

파일 목록이 아니라 살롱의 상담 룩북처럼 보인다. 다음 방문 때 빠르게 다시 열 수 있어야 한다.

### 상태 정의

| 상태 | 모습 |
| --- | --- |
| empty | 첫 상담을 시작하는 Style Board CTA. |
| 로딩 | 날짜 그룹 skeleton. |
| 오류 | 읽을 수 없는 기록 수와 파일 위치 안내. |
| 완료 | 최신순 룩북 카드, 컷/컬러 필터, 비교 재추가 버튼. |

## 자기검증

이 화면 설계는 무드보드/진단 앱이 아니라 살롱 손님에게 바로 보여주는 `Gate → Style Board → Color Board → Client Preview → Compare → Lookbook` 상담 도구로 재정렬한다.

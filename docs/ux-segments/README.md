# Hairloom 사용자군별 UX 구상

## 결론

Hairloom의 첫 번째 실전 제품은 **미용사와 고객이 함께 쓰는 살롱 상담 도구**가 가장 적합하다.

현재 강점은 다음과 같다.

- 전면·측면·후면 3각 입력 및 결과 비교
- 기장·모질·펌 굵기 기반 DESIGN LOCK
- 6,500개 헤어 설계 온톨로지
- 여러 후보를 나란히 검토하는 디자인북 방식
- 사용자별 로컬 API 및 사진 보관

이 강점은 일반 고객의 즉흥적인 놀이보다, 미용사가 상담 중 “어디까지 자르고 어떤 굵기의 컬을 만들 것인지” 합의하는 상황에서 더 큰 가치를 만든다.

## 우선순위

| 우선순위 | 사용자군 | 제품 역할 | 이유 |
|---:|---|---|---|
| P0 | 미용사·헤어 디자이너 | 핵심 유료 제품 | 전문 필터와 3각 결과를 실제 상담에 바로 사용 가능 |
| P0 | 일반 고객 | 유입·체험 제품 | 쉬운 셀프 체험으로 상담 예약과 공유를 유도 |
| P1 | 살롱 원장·매니저 | 운영 확장 | 고객 기록, 직원 표준화, 재방문 상담 필요 |
| P1 | 프랜차이즈·헤어 회사 | 엔터프라이즈 | 브랜드 스타일 통제, 지점별 통계, 캠페인 운영 가능 |
| P1 | 헤어 제품·커머스 회사 | 상품 연결 | 스타일 결과를 펌·케어·스타일링 제품과 연결 가능 |
| P2 | 미용 교육기관 | 교육 제품 | 커트·펌 구조와 각도별 차이를 과제·채점에 활용 가능 |
| P2 | 콘텐츠 크리에이터·스튜디오 | 제작 도구 | 대량 시안, 촬영 전 콘셉트, 썸네일 및 룩북 기획 가능 |
| P2 | 웨딩·가발·특수 상담 | 전문 버티컬 | 업두·가발·민감한 외모 상담에 특화 가능 |

## 공통 코어

모든 사용자군에서 공유해야 하는 기능:

1. 사용자/고객 사진 입력과 명시적 동의
2. 성별이 아닌 헤어 구조 중심의 검색도 허용
3. 기장·모질·펌·앞머리·가르마 필터
4. 전면·측면·후면 DESIGN LOCK 생성
5. 후보 비교와 즐겨찾기
6. 결과 내보내기 및 삭제
7. API 비용·요청 상태·실패 이유 표시
8. 사진 보관 기간과 개인정보 정책

## 제품군

- `Hairloom Client`: 일반 고객 셀프 체험
- `Hairloom Pro`: 미용사 상담
- `Hairloom Salon`: 살롱 운영
- `Hairloom Enterprise`: 프랜차이즈·브랜드
- `Hairloom Academy`: 교육
- `Hairloom Studio`: 콘텐츠 제작
- `Hairloom Care`: 웨딩·가발·특수 상담

# Hairloom Pro — 미용사·헤어 디자이너 UX

## 사용자

- 고객 요구를 기술적인 시술 계획으로 번역하는 디자이너
- 전·측·후 결과를 보고 기장과 실루엣을 합의해야 하는 전문가
- 상담 시간과 재시술·불만을 줄이고 싶은 미용사

## 핵심 문제

고객이 가져온 사진 한 장은 측면·후면 구조와 실제 기장을 설명하지 못한다. 같은 이름의 스타일도 컬 굵기·레이어 시작점·네이프가 다르다.

## 권장 흐름

1. 고객 기본 정보 및 사진 동의
2. 현재 모질·밀도·손상도 기록
3. 길이 랜드마크 선택
4. 6,500개 카탈로그 전문 검색
5. 후보 6~12개 임시 보드
6. 전·측·후 생성
7. 고객과 비교하며 1개 승인
8. 시술 명세 저장
   - 목표 길이
   - 레이어 시작점
   - 앞머리·가르마
   - 컬 종류와 mm
   - 네이프·사이드 구조
   - 관리 난이도
9. 상담 카드·시술 메모 내보내기

## 핵심 화면

- 전문 필터 패널
- 고객 상담 보드
- 전·측·후 동기 비교
- DESIGN LOCK 상세
- 시술 가능성·주의사항
- 상담 승인 서명

## 필수 기능

- 디자인 ID 검색
- 고객 사진 위 별도 메모
- 결과별 “가능 / 수정 필요 / 비권장” 표시
- 실제 모질과 디자인 권장 모질 비교
- 생성 결과가 시술 보장이 아니라는 명시
- 상담 전후 버전 기록

## 성공 지표

- 평균 상담 시간
- 상담 후 디자인 변경 횟수
- 재시술·컴플레인 감소
- 승인 카드 사용률
- 고객 재방문율

## 제외할 것

- 예약·결제 전체 시스템
- 상품 광고 중심 UI
- 자동 시술 보장 문구

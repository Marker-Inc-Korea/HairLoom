## 사용자군에 따라 바뀌어야 하는 것

### 언어

- 고객: “턱선 정도”, “관리 쉬움”, “얼굴이 길어 보이지 않게”
- 미용사: “38mm C컬”, “네이프 25mm”, “광대 시작 레이어”
- 회사: “캠페인 스타일 ID”, “승인 버전”, “지점 사용량”

### 후보 수

- 고객에게 6,500개를 직접 노출하면 실패한다.
- 고객은 질문 후 3~6개만 본다.
- 미용사는 검색과 필터로 수백 개까지 접근한다.
- 기업은 승인된 브랜드 카탈로그만 본다.

### 결과의 의미

- 고객: 영감과 상담 자료
- 미용사: 시술 합의를 위한 설계 초안
- 회사: 브랜드 운영 자산
- 교육기관: 구조 분석 및 평가 자료

## 데이터 계층

1. 공통 디자인 온톨로지: 6,500개 ID
2. 사용자군별 노출 규칙
3. 조직별 승인 스타일
4. 고객별 사진·상담 기록
5. 생성 결과와 프롬프트 버전

사진과 조직 데이터는 디자인 온톨로지와 분리해야 한다.

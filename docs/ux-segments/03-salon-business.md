# Hairloom Salon — 살롱 원장·프랜차이즈 UX

## 사용자

- 여러 디자이너의 상담 품질을 관리하는 원장
- 지점별 서비스를 표준화하는 프랜차이즈 본사
- 고객 재방문과 상담 기록을 운영 자산으로 만들려는 조직

## 핵심 문제

개별 미용사의 감각과 설명 방식이 달라 상담 결과가 일관되지 않는다. 고객 사진과 생성 결과를 조직이 보관할 경우 개인정보·권한 문제가 커진다.

## 살롱 원장 흐름

1. 오늘 예약과 상담 대기 목록
2. 담당 디자이너 배정
3. 고객 동의 확인
4. Hairloom Pro 상담 수행
5. 승인된 시술 카드 저장
6. 다음 방문 시 이전 기록과 변경점 비교
7. 월별 상담·재방문 지표 확인

## 프랜차이즈 본사 흐름

1. 시즌 스타일 카탈로그 구성
2. 본사 승인 디자인 ID 배포
3. 지점별 노출·사용 권한 설정
4. 지점이 상담 결과를 생성
5. 캠페인 사용률과 선호 스타일 집계
6. 실패율·비용·쿼터 모니터링

## 핵심 화면

- 예약·상담 대기열
- 직원/지점 권한
- 승인 스타일 라이브러리
- 고객 동의·삭제 요청
- API 비용과 생성 실패율
- 지점별 통계

## 권한

- 디자이너: 담당 고객만
- 원장: 매장 고객과 직원 통계
- 본사: 익명화된 집계와 브랜드 카탈로그
- 관리자: 비용·정책·감사 로그

## 성공 지표

- 상담 표준 카드 사용률
- 지점별 캠페인 적용률
- 고객 재방문율
- 직원별 생성 성공률
- 사진 삭제 요청 처리 시간

## 위험

- 직원 감시 도구로 오해
- 본사가 현장 창의성을 제한
- 고객 사진의 과도한 중앙 보관
- 지점별 API 비용 폭증

# Hairloom Academy / Studio — 교육·콘텐츠 제작 UX

## Academy 사용자

- 미용학교 강사와 학생
- 커트·펌 구조를 각도별로 학습하는 교육기관
- 과제와 피드백을 표준화하려는 조직

## Academy 흐름

1. 강사가 디자인 ID와 학습 목표 지정
2. 학생이 전·측·후 구조 분석
3. 길이·레이어·컬 굵기 입력
4. 예상 결과 생성
5. 정답이 아니라 설계 근거를 제출
6. 강사가 루브릭으로 피드백

## Academy 핵심 기능

- 디자인 구조 분해
- 전·측·후 주석
- mm·랜드마크 퀴즈
- 학생별 제출물
- DESIGN LOCK 비교
- AI 사용 기록

## Studio 사용자

- 뷰티 콘텐츠 크리에이터
- 촬영 스튜디오와 아트 디렉터
- 룩북·광고·썸네일을 기획하는 팀

## Studio 흐름

1. 프로젝트와 촬영 콘셉트 생성
2. 모델 사진·의상·무드 등록
3. 후보 헤어를 대량 탐색
4. 전·측·후 또는 필요한 각도만 생성
5. 감독·클라이언트 승인
6. 룩북·샷리스트로 내보내기

## Studio 핵심 기능

- 프로젝트 보드
- 배치 생성과 큐
- 비율·해상도 선택
- 승인·코멘트
- 생성 비용 예산
- 라이선스·사용처 기록

## 성공 지표

### Academy

- 과제 완성률
- 구조 분석 정확도
- 강사 피드백 시간

### Studio

- 콘셉트 승인 시간
- 촬영 전 수정 횟수
- 프로젝트당 생성 비용

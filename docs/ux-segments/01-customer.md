# Hairloom Client — 일반 고객 UX

## 사용자

- 헤어 용어를 잘 모르는 사람
- 미용실 방문 전 실패 가능성을 줄이고 싶은 사람
- 새로운 스타일을 가볍게 체험하고 공유하려는 사람

## 핵심 문제

고객은 “허쉬컷 34mm S컬”보다 “관리하기 쉽고 얼굴이 덜 길어 보이는 스타일”을 원한다. 6,500개를 직접 탐색시키면 선택 피로가 발생한다.

## 권장 흐름

1. 목적 선택: 변화 크게 / 안전하게 / 기장 유지 / 관리 쉽게
2. 현재 사진: 전면 필수, 측·후면 선택
3. 쉬운 질문 3~5개
   - 자를 수 있는 최대 길이
   - 아침 손질 시간
   - 앞머리 허용 여부
   - 펌 허용 여부
   - 피하고 싶은 스타일
4. 후보 3개 생성
5. 전·측·후 확인
6. 하나를 선택해 “미용사에게 보여줄 카드” 생성
7. 사진·결과 삭제 또는 기기 저장

## 핵심 화면

- 고민 선택
- 길이 슬라이더
- 손질 난이도
- 후보 3개 비교
- 미용사 전달 카드
- 개인정보 삭제

## 문구 원칙

전문 용어를 번역한다.

```text
34mm S컬 → 자연스러운 중간 굵기 웨이브
네이프 → 목덜미 부분
페이스프레임 → 얼굴선을 감싸는 층
```

## 성공 지표

- 사진 입력 후 결과 완료율
- 후보 저장률
- 공유율
- 상담 예약 전환
- 결과 생성 후 즉시 삭제 선택률

## 제외할 것

- 6,500개 직접 목록
- 복잡한 mm 필터
- 직원·조직 관리
- 대량 생성
- 전문 시술 레시피 확정

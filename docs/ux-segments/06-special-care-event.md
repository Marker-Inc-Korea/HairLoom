# Hairloom Care — 웨딩·가발·특수 상담 UX

## 웨딩·행사 사용자

- 신부·신랑·혼주
- 웨딩 헤어 스타일리스트
- 공연·행사 업두를 준비하는 팀

## 웨딩 흐름

1. 행사 유형·의상·베일·장식 입력
2. 현재 머리 길이와 익스텐션 가능 여부
3. 업두·하프업·포니 후보 선택
4. 전면·측면·후면 결과 확인
5. 장식 위치와 고정점 메모
6. 당일 시술 카드 확정

## 가발·헤어피스 상담 사용자

- 길이·밀도·가르마를 비교하려는 고객
- 가발숍·맞춤 가발 상담사
- 외형 변화가 민감한 사용자

## 가발 상담 흐름

1. 민감 정보와 사진 사용 동의
2. 얼굴보다 실루엣 중심 옵션
3. 길이·밀도·가르마·헤어라인 선택
4. 제품 재고 또는 맞춤 제작 사양 연결
5. 착용·관리 안내
6. 사진과 상담 기록의 보관 기간 선택

## 핵심 기능

- 얼굴 비노출 또는 마네킹 모드
- 베일·장식·헤어피스 위치 주석
- 익스텐션·가발 사용 여부
- 실제 모발 길이와 구현 가능성 분리
- 즉시 삭제
- 상담 기록 암호화

## 금지 사항

- 의료적 치료 결과를 암시
- 탈모 원인 진단
- 실제 시술·가발 착용 결과 보장
- 사용자의 민감 상태를 마케팅에 활용

## 성공 지표

- 행사 당일 스타일 변경 감소
- 제품 사양 합의 시간
- 비노출 모드 사용률
- 삭제 요청 처리 시간

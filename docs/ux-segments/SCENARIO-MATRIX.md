|---|---|---|---|---|---|---|
| 일반 고객 | 집에서 스타일 탐색 | 나에게 어울리는 후보를 빠르게 찾기 | 쉬운 질문 3~5개 | 후보 3개와 미용사에게 보여줄 카드 | 완료율, 공유율, 예약 전환 | 선택 피로, 결과 과신 |

| 단골 고객 + 미용사 | 이전 시술 변경 | 과거 기록에서 안전하게 변화 | 고객 히스토리 | 이전 대비 변경점과 새 시안 | 재방문율, 재시술 만족도 | 기록 보관 동의 |

| 프랜차이즈 본사 | 브랜드 캠페인 배포 | 지점별로 동일한 시즌 룩 제안 | 캠페인 대시보드 | 승인된 스타일 세트와 사용량 | 캠페인 적용률 | 현장 창의성 제한 |
| 헤어 브랜드 | 제품 추천 연결 | 스타일 결과를 상품 구매로 전환 | 스타일/모질 선택 | 시술 후 관리 루틴과 상품 묶음 | 상품 클릭·구매율 | 과도한 광고화 |
| 교육기관 | 커트·펌 수업 | 구조를 각도별로 이해하고 평가 | 수업·과제 목록 | 설계 분석, 학생 시안, 루브릭 | 과제 완성도 | AI 의존, 저작권·평가 공정성 |
| 콘텐츠 제작자 | 촬영 전 룩 개발 | 여러 콘셉트를 빠르게 비교 | 프로젝트 보드 | 룩북·샷리스트·승인 시안 | 제작 시간 단축 | 대량 생성 비용 |
| 웨딩 고객·스타일리스트 | 행사 업두 결정 | 의상·장식과 헤어를 사전 합의 | 행사 정보·의상 사진 | 전후좌우 업두 시안 | 당일 변경 감소 | 장식·베일 물리 제약 |
| 가발·특수 상담 | 외형 변화 상담 | 부담 없이 가능한 실루엣 탐색 | 민감 정보 동의 | 가발 길이·밀도·가르마 시안 | 상담 만족도 | 의료 오인, 개인정보 민감도 |

## 공통 상황 분류

### 혼자 쓰는 상황

- 집에서 탐색
- 예약 전 후보 저장
- 가족·친구와 공유
- 콘텐츠 콘셉트 초안

필요 UX: 짧은 질문, 큰 이미지, 전문 용어 번역, 후보 수 제한.

### 전문가와 함께 쓰는 상황

- 살롱 상담
- 웨딩 상담
- 가발 상담
- 교육 피드백

필요 UX: 기술 용어, 각도별 비교, 수치화된 길이·컬 굵기, 메모와 승인.

### 조직이 쓰는 상황

- 프랜차이즈 캠페인
- 직원 교육
- 브랜드 상품 추천
- 지점 통계

필요 UX: 권한, 승인, 템플릿, 감사 로그, 비용 한도, 데이터 보존 정책.

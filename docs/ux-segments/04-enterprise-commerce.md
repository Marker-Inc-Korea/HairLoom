# Hairloom Enterprise — 헤어 회사·브랜드·커머스 UX

## 사용자

- 헤어 제품·가전·펌제·케어 브랜드
- 스타일 캠페인을 운영하는 마케팅팀
- 상품을 사용 상황과 연결하려는 커머스 조직

## 핵심 문제

상품 카탈로그는 제품 중심이고 고객은 원하는 결과 중심으로 생각한다. 스타일 결과에 상품을 과도하게 붙이면 Hairloom의 신뢰가 광고로 변한다.

## 권장 흐름

1. 회사가 승인 스타일 세트 선택
2. 각 디자인 ID에 상품·시술·관리 루틴 연결
3. 고객이 스타일을 체험
4. 결과 이후에만 관련 루틴 제안
5. 상품 구매·살롱 예약·콘텐츠 열람 중 하나 선택
6. 캠페인 성과를 익명 집계

## 제품 유형별 활용

### 펌제·살롱 브랜드

- 컬 굵기와 모질 적합성
- 시술 가능 범위
- 살롱 위치와 예약

### 헤어 가전

- 드라이어·고데기·컬링 아이론 규격
- 집에서 재현 가능한 정도
- 예상 손질 시간

### 케어 제품

- 손상도와 펌 유형에 맞는 루틴
- 세정·보습·열 보호
- 유지 기간 안내

### 가발·익스텐션

- 길이·밀도·가르마·네이프
- 착용 방식과 관리
- 실제 제품 재고 연결

## 핵심 화면

- 브랜드 승인 스타일
- 디자인 ID ↔ 상품 매핑
- 캠페인 버전과 기간
- API·생성 비용 한도
- 전환 퍼널
- 상품 노출 빈도 제어

## 성공 지표

- 결과 확인 후 상품 클릭률
- 스타일별 전환율
- 과도한 광고 이탈률
- 캠페인별 생성 비용

## 원칙

- 생성 전 광고 노출 금지
- 상품이 스타일 결과를 바꾸지 않음
- 협찬·추천 이유 표시
- 특정 제품의 효과를 과장하지 않음

# Hairloom Pro 시술 가능성 판정 규칙

## 판정 단계

| 상태 | 의미 | 선택 |
|---|---|---|
| 가능 | 현재 입력 조건에서 보수적 규칙상 상담 가능 | 선택 가능 |
| 조건부 | 테스트, 강도 조정, 붙임머리·피스 또는 미용사 확인 필요 | 선택 가능, 조건 표시 |
| 불가 | 현재 조건에서 해당 사양 그대로 시술하지 않음 | 선택 불가, 이유 표시 |

판정은 의료 진단이나 최종 시술 판단이 아니다. 미용사의 현장 모발 진단을 대체하지 않는다.

## 길이 기준

| 목표 기장 | 결과에서 보이는 기준 길이 |
|---|---:|
| 초단기장 | 8cm |
| 숏 | 18cm |
| 미디엄 | 36cm |
| 롱 | 56cm |
| 엑스트라 롱 | 78cm |

필요한 시술 전 길이는 다음과 같이 계산한다.

```text
시술 전 필요 길이 = 목표로 보이는 길이 ÷ (1 - 예상 수축률)
```

## 펌·모질별 예상 수축률

| 유형 | 수축률 |
|---|---:|
| 내추럴 스트레이트 | 0% |
| 내추럴 웨이브 | 4% |
| 내추럴 컬 | 12% |
| 내추럴 코일 | 22% |
| 루즈 C컬 | 3% |
| 타이트 C컬 | 7% |
| 루즈 S컬 | 5% |
| 타이트 S컬 | 10% |
| 바디 웨이브 | 4% |
| 워터 웨이브 | 8% |
| 스파이럴 | 14% |
| 히피 펌 | 18% |

이 값은 UX 초기 가설이다. 약제, 롯드, 모발 굵기와 시술 방식에 따라 달라지므로 실제 제품에서는 살롱별 보정값이 필요하다.

## 붙임머리·헤어피스

여성 프로필에서 토글로 활성화한다.

- 부족 길이 18cm 이하: 헤어피스 또는 부분 연장 조건부
- 부족 길이 18~50cm: 붙임머리 조건부
- 부족 길이 50cm 초과: 불가
- 심한 손상 또는 낮은 모량에서 큰 연장이 필요한 경우: 불가
- 길이가 충분하면 붙임 옵션을 사용하지 않음

붙임 옵션은 모발 손상·두피 상태·결합 방식 확인 없이 “가능” 판정을 만들지 않는다.

## 화학 시술 제한

다음 조건은 펌을 불가 처리한다.

- 심한 손상
- 탈색 2회 이상
- 3개월 이내 펌 이력

다음 조건은 조건부 처리한다.

- 중간 손상
- 탈색 1회
- 3~6개월 펌 이력
- 기존 곱슬·코일에 다른 펌 패턴을 중첩
- 손상 모발에서 “확실하게” 강도 선택

조건부 확인:

- 탄력·인장 테스트
- 테스트 컬
- 중복 시술 구간
- 약제 강도 하향
- 컬 지름 확대
- 손상 구간 커트

## 자연 모질 적합성

자연 모질 피니시는 화학 변형을 의미하지 않는다.

- 현재 모질과 같은 자연 피니시: 가능
- 드라이·아이론·세팅으로 일시 재현 가능: 조건부
- 자연 모질만으로 구조적 재현이 어려움: 불가

예를 들어 직모에서 “내추럴 코일”을 선택하는 것은 펌이 아니라 자연 코일을 전제로 한 디자인이므로 불가다. 화학 컬을 원하면 스파이럴·히피 펌 등 별도 피니시를 선택한다.

## 모량 제한

낮은 모량에서 다음 구조는 조건부다.

- 블런트
- 원랭스
- 큰 라운드 볼륨
- 높은 끝선 밀도

미용사는 레이어 감소, 끝선 보강, 피스 사용 또는 다른 구조를 제안한다.

## 실제 제품 전환 전에 필요한 검증

1. 헤어 디자이너 5명 이상에게 수축률 범위 검토
2. 펌 약제·롯드별 보정값 조사
3. 손상 단계 판정표 정의
4. 붙임머리 방식별 최대 연장 길이와 금기 조건 정의
5. 곱슬·코일 모발 전문가 검토
6. 잘못된 “가능” 판정을 가장 심각한 오류로 두는 테스트

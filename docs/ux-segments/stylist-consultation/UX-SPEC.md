# Hairloom Pro — 미용사·고객 공동 상담 UX 상세

## 제품 정의

Hairloom Pro는 고객이 혼자 정답을 고르는 서비스가 아니다. 미용사와 고객이 같은 화면을 보며 **취향 → 디자인 구조 → 시술 가능한 사양**으로 합의하는 상담 도구다.

## 탐색 구조

### 1단계: 현재 모발 진단

필수 입력:

- 여성/남성 프로필
- 현재 기장과 실제 길이(cm)
- 자연 모질: 직모, 반곱슬, 곱슬, 코일
- 모량
- 손상도
- 탈색 이력
- 최근 펌 이력
- 여성의 붙임머리·헤어피스 허용 토글

### 2단계: 구조 디자인북 500개

마스터 카탈로그의 코어 6,000개를 다음 기준으로 묶는다.

```text
성별 2 × 목표 기장 5 × 기본 실루엣 10 × 프런트 5 = 500개
```

이 단계에서는 컬이나 감성 표현을 섞지 않는다. 고객과 미용사는 다음 구조만 고른다.

- 목표 기장
- 전체 실루엣
- 레이어·끝선
- 앞머리·가르마

각 카드에는 선택 이후 나오는 288개 바리에이션의 판정을 집계해 보여준다.

```text
바로 가능 144
조건부 96
불가 48
전체 288
```

### 3단계: 선택 구조의 바리에이션 288개

```text
모질·펌 12
× 느낌 8
× 표현 강도 3
= 구조 하나당 288개
```

모질·펌:

- 자연 직모·웨이브·컬·코일
- 루즈/타이트 C컬
- 루즈/타이트 S컬
- 바디 웨이브
- 워터 웨이브
- 스파이럴
- 히피 펌

느낌:

- 자연스러운
- 부드러운
- 단정한
- 우아한
- 시크한
- 로맨틱한
- 경쾌한
- 과감한

표현 강도:

- 은은하게
- 균형 있게
- 확실하게

### 4단계: 고객의 느낌 입력

고객은 전문 용어 대신 문장으로 말한다.

```text
너무 꾸민 느낌은 싫고 부드럽지만 단정했으면 좋겠어요.
```

시스템은 이 문장을 디자인을 임의 생성하는 명령으로 쓰지 않는다. 기존 288개 결과의 정렬과 필터에 사용한다.

예시 해석:

```text
부드러운 + 단정한
```

### 5단계: 상담 합의

최종 카드는 다음을 포함한다.

- 목표 기장과 보이는 길이
- 시술 전 필요한 실제 길이
- 컬 종류와 지름
- 예상 길이 수축률
- 붙임머리·헤어피스 필요 여부
- 손상 및 화학 시술 조건
- 고객이 입력한 느낌
- 고유 DESIGN ID
- 미용사 현장 확인 항목

## 핵심 원칙

1. 불가능한 디자인도 숨기기만 하지 않고 불가 이유를 설명한다.
2. 붙임머리 토글은 불가능을 가능으로 바꾸는 것이 아니라 조건부 후보로 바꾼다.
3. 펌 결과의 보이는 길이가 아니라 수축 전 필요한 실제 길이를 계산한다.
4. 심한 손상과 반복 화학 이력은 미적 취향보다 우선한다.
5. AI 이미지는 시술 보장이 아닌 상담 자료다.
6. 6,500개 목록을 한 화면에 펼치지 않고 구조와 바리에이션으로 단계화한다.

# 미용사·고객 공동 상담 UX 기획

이 폴더는 `ux/stylist-consultation` 브랜치의 UX 구조와 시술 가능성 판정 기준만 정리한다.

## 핵심 구조

```text
현재 모발 진단
→ 500개 구조 디자인북
→ 선택 구조의 288개 바리에이션
→ 고객 느낌 입력과 정렬
→ 가능/조건부/불가 판정
→ 시술 상담 합의
```

## 문서

- [상세 UX 구조](./UX-SPEC.md)
- [시술 가능성 규칙](./FEASIBILITY-RULES.md)

## 화면 제작 원칙

- 이 브랜치에서는 프론트엔드를 만들지 않는다.
- 캐릭터, 마네킹, 임의 삽화와 장식용 인물 이미지를 사용하지 않는다.
- 화면 시안을 만들게 되더라도 설명 문장을 화면에 길게 넣지 않는다.
- 실제 헤어 이미지, 필터, 상태, 수치, 선택 결과가 중심이 되어야 한다.
- `가능`, `조건부`, `불가`처럼 판단에 필요한 짧은 문구만 사용한다.

## 현재 범위

현재 작업은 사용자 흐름, 카탈로그 단계, 펌 수축, 손상 제한, 붙임머리·피스 조건을 정의한 기획 문서다. 앱 화면과 이미지 생성 기능에는 연결하지 않는다.

# 미용사·고객 공동 상담 UX 기획

이 폴더는 Hairloom PRO의 상담 UX 구조와 시술 가능성 판정 기준을 정리한다. 현재 런타임 구현은 루트 `consultation/`에 있으며, 등록 모델 생성 대기 흐름과 데이터 경계는 [`../../MODEL-PREVIEW-FLOW.md`](../../MODEL-PREVIEW-FLOW.md)에 기록한다.

## 핵심 구조

```text
현재 모발 진단
→ 500개 구조 디자인북
→ 선택 구조의 288개 바리에이션
→ 고객 느낌 입력과 정렬
→ 가능/조건부/불가 판정
→ 시술 상담 합의
```

## 문서

- [상세 UX 구조](./UX-SPEC.md)

## 화면 구현 원칙

- 실제 헤어 이미지, 필터, 상태, 수치, 선택 결과가 중심이어야 한다.
- 캐릭터, 마네킹, 임의 삽화와 장식용 인물 이미지를 운영 화면에 사용하지 않는다.
- 긴 설명 대신 `가능`, `조건부`, `불가`, `생성 대기`처럼 판단에 필요한 짧은 상태 문구를 사용한다.
- 등록 모델 사진은 브라우저 로컬 `DISPLAY ONLY` 자산이며 `queued`·`active`에만 표시되고 Provider 입력이나 handoff에 포함하지 않는다. 권리 만료·철회와 관리자 일괄 변경은 열린 PRO 탭에 즉시 반영한다.
- 현재 앱은 `/consultation/`에서 `SOURCE → PROFILE → STRUCTURE → VARIATION → COMPARE → LOCK` 흐름으로 연결되어 있다.

## 현재 범위

상담 도메인 문서와 실제 PRO 화면이 함께 유지된다. 구조·바리에이션·시술 가능성 규칙은 이 폴더에서, 런타임 큐·이미지 전송·등록 모델 표시 계약은 루트 코드와 `docs/MODEL-PREVIEW-FLOW.md`에서 검증한다.

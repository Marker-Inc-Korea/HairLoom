# Hairloom 1.0.0 기술 변경 내역

이 문서는 일반 사용자를 위한 README에서 분리한 구현·보안·검증 세부사항입니다.

## 네이티브 AI Provider

- 실제 헤어 분석과 이미지 편집은 Android·iOS 네이티브 코드에서만 실행합니다.
- 분석 엔드포인트: `https://api.openai.com/v1/responses`
- 분석 모델: `gpt-4.1-mini`
- 이미지 편집 엔드포인트: `https://api.openai.com/v1/images/edits`
- 이미지 모델: `gpt-image-2`
- 브라우저와 WebView JavaScript에는 API 키 입력 필드, Bearer 요청 또는 임의 Provider URL 설정이 없습니다.

## 자격 증명과 개인정보

- Android API 키는 Android Keystore로 보호합니다.
- iOS API 키는 `kSecAttrAccessibleWhenUnlockedThisDeviceOnly` Keychain 항목으로 보호합니다.
- `연결 삭제`는 Provider 키를 제거합니다.
- `모든 고객 데이터 삭제`는 준비 원본, 생성 결과, 작업 파일과 배치 저널을 제거합니다.
- 완료·취소된 고객 데이터는 앱 시작 시 7일 기준으로 정리합니다.
- API 키, 고객 사진, 생성 결과, 인증 파일, 로컬 SDK 경로와 서명 재료는 저장소에 포함하지 않습니다.

## 원본 계보

- 사용자가 준비한 원본 사진만 Provider 입력으로 허용합니다.
- 생성 이미지, 카탈로그 이미지와 등록 모델 이미지는 이후 분석·생성 입력으로 재사용하지 않습니다.
- 카메라와 갤러리는 같은 준비 원본 파이프라인을 사용합니다.
- `source_*`와 `output_*` 네이티브 핸들은 구분되며 출력 핸들은 원본 입력으로 거부합니다.

## 고정 결과 배치와 복구

- 생성 배치는 고정 100개 결과 슬롯을 사용합니다.
- 슬롯 인덱스, 디자인 ID, 원본 해시와 재시도 소유권은 완료 순서와 무관하게 유지합니다.
- 중단된 작업은 같은 슬롯의 `retryable` 상태로 복원합니다.
- 전역 동시 실행 수는 Android 4, iOS 2입니다.
- 재시도는 추가 과금 요청이 될 수 있으므로 API 프로젝트의 사용량·예산 한도를 설정해야 합니다.

## 분석 제한

- 신원, 나이, 민족, 얼굴형, 신체, 건강 또는 성 정체성을 추론하지 않습니다.
- 확인할 수 없는 탈색·펌·붙임머리 이력은 사용자가 제공하지 않으면 미상으로 처리합니다.
- 생성 프롬프트는 얼굴·몸·배경·의상을 유지하고 헤어만 변경하도록 제한합니다.

## 남은 실제 환경 검증

- 지원되는 실제 iOS·Android 기기에서 카메라·갤러리, 보안 저장소, 종료·재시작, 메모리·열 동작과 데이터 삭제를 검증해야 합니다.
- 사용자가 직접 입력한 별도 과금 OpenAI API 키로 실제 분석, 100개 결과 완료와 재시작 복원을 검증해야 합니다.
- GitHub Android APK는 debug-signed sideload 배포이며 Play Store·App Store 서명 산출물이 아닙니다.

## English summary

Hairloom keeps OpenAI credentials and traffic in native Android/iOS code, accepts only app-owned prepared originals as Provider inputs, owns 100 deterministic result slots with restart recovery, and stores customer data in app-private storage. The browser shell cannot accept credentials or call the Provider. Physical-device and real credentialed Provider acceptance remain release-owner tasks.

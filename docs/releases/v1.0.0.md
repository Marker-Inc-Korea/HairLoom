# Hairloom 1.0.0

Hairloom 1.0.0은 컴퓨터에서 실행하는 공개 소스와 Android APK를 제공하는 첫 정식 배포입니다. Play Store와 App Store 배포는 이번 버전에 포함하지 않습니다.

## 배포 대상

- **컴퓨터:** Node.js 20 이상에서 저장소를 내려받아 로컬 웹 셸 실행
- **Android:** Android 6.0/API 23 이상, target SDK 35의 GitHub APK 직접 설치
- **iOS:** 소스와 Simulator 빌드 구성은 포함하지만 일반 사용자용 바이너리 배포는 보류

## 주요 기능

- `SOURCE → RESULTS → LOCK` 상담 흐름
- 카메라와 갤러리의 동일한 준비 원본 파이프라인
- 사용자가 준비한 원본만 Provider 입력으로 허용
- 고정 100개 슬롯과 재시작·재시도 소유권 복원
- 원본 비율을 유지하는 확대 화면과 1–6개 shortlist
- 고객 데이터 전체 삭제와 7일 정리 정책
- iOS Keychain·Android Keystore 기반 API 자격 증명 보호

## OpenAI API

Android 네이티브 앱의 `이미지 생성 연결`에서 별도 과금되는 개인 OpenAI API 키를 입력합니다.

- 분석: `gpt-4.1-mini` · `https://api.openai.com/v1/responses`
- 이미지 편집: `gpt-image-2` · `https://api.openai.com/v1/images/edits`
- ChatGPT Plus/Pro 구독과 OpenAI API 과금은 별개입니다.
- 컴퓨터의 브라우저 웹 셸은 API 키 입력이나 Provider 생성을 지원하지 않습니다.

## 검증 기준

- 106개 Node 테스트
- 1,080개 taxonomy 및 6,500개 master catalog 검증
- Android Java 21·SDK 35 clean APK 빌드
- APK SHA-256 및 Signature Scheme v1/v2 검증
- iOS Simulator 빌드·설치·실행
- 1440×1000, 834×1112, 390×844 반응형 검증

## APK 주의사항

GitHub APK는 debug-signed sideload 배포입니다. 새 버전의 서명 인증서가 이전 APK와 다르면 기존 Preview를 제거한 뒤 설치해야 하며, 제거 시 앱 전용 원본·출력·설정이 초기화됩니다. 반드시 함께 제공되는 `.sha256` 파일로 무결성을 확인하세요.

## 알려진 제한

- 컴퓨터 브라우저에서는 카탈로그와 상담 UI를 확인할 수 있지만 실제 Provider 분석·생성은 실행하지 않습니다.
- Play Store, App Store, TestFlight 배포는 보류되었습니다.
- 실제 iOS·Android 기기에서의 전체 센서·백그라운드·메모리·열 검수는 최종 승인 전 필요합니다.
- 실제 별도 과금 API 키로 분석부터 100개 완료, 복원, shortlist, LOCK까지의 최종 E2E 승인이 남아 있습니다.

## English summary

Hairloom 1.0.0 is the first source release for computer/local use and direct Android APK installation. It preserves the native-only credential boundary, prepared-original-only Provider input, deterministic 100-slot recovery, private customer storage, and `SOURCE → RESULTS → LOCK` flow. Store distribution is deferred. The project is source-available under PolyForm Noncommercial 1.0.0; commercial use requires a separate written license.

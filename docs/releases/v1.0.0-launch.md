# Hairloom 1.0.0 is public

Hairloom 1.0.0 is now publicly available.

Hairloom is a source-available hairstyle consultation project built around the `SOURCE → RESULTS → LOCK` flow. This release provides:

- a local web shell for Windows, macOS, and Linux;
- a directly installable APK for Android 6.0 and newer;
- fixed 100-slot result ownership and restart recovery;
- prepared-original-only Provider lineage;
- API-key protection through Android Keystore and iOS Keychain; and
- Korean and English installation, API, and contribution guidance.

Repository:
https://github.com/Marker-Inc-Korea/HairLoom

Android 1.0.0:
https://github.com/Marker-Inc-Korea/HairLoom/releases/tag/v1.0.0

The computer web shell is for local UI and catalog review. Real analysis and image generation run only in the native Android/iOS app and require a user-owned, separately billed OpenAI API key. ChatGPT subscriptions and API billing are separate.

Hairloom is noncommercial source-available software under PolyForm Noncommercial 1.0.0. Commercial use requires a separate written license from NomaDamas.

Play Store and App Store distribution is deferred. The GitHub APK is a debug-signed sideload build; verify its SHA-256 checksum before installation.
